# 🐳 Servidor Nginx en Docker – Proyecto DevOps

¡Bienvenido a mi primer proyecto práctico de DevOps! 🚀  
Este repositorio contiene una implementación sencilla pero funcional de un servidor web Nginx corriendo en un contenedor Docker, ideal para aprender los fundamentos de la contenerización y la configuración de servicios web.

---

## 🔧 ¿Qué incluye?

- Imagen personalizada de Nginx con configuración propia.
- Página HTML servida desde el contenedor.
- Orquestación con Docker Compose.
- Archivos bien documentados y listos para producción básica.

---

## 📚 Tecnologías utilizadas

- Docker & Docker Compose  
- Nginx  
- HTML  
- Linux (base del contenedor)

---

## 🎯 Objetivo del proyecto

Este proyecto forma parte de mi ruta de aprendizaje como estudiante de ASIR, orientado a adquirir experiencia práctica en DevOps.  
El objetivo es entender cómo se construyen, configuran y despliegan servicios en contenedores.

---

## 🚀 Cómo ejecutarlo


git clone https://github.com/Henner13/Servidor-Web-Nginx.git
cd servidor-web-nginx
docker-compose up
